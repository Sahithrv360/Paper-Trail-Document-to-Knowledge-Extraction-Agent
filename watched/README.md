# Public Invoice Samples

These 501 JPG files are samples from `katanaml-org/invoices-donut-data-v1` (425 train, 50 validation, 26 test). The Hugging Face dataset card declares MIT; the cited source invoices declare CC BY 4.0. See [`../data/README.md`](../data/README.md) for provenance and attribution.

This folder is also the application's default live intake folder. Point `WATCH_FOLDER` to an empty intake directory before starting the watcher if you do not want it to enqueue all sample images automatically.
